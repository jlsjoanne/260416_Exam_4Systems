### 火箭隊培訓營 第22梯 後端組 四大系統抽考

使用ASP.NET Webform框架，資料庫為Microsoft SQL Server，後端以C#語言開發。

<u>系統列表</u>
- 以下系統均有後台管理，具Edit權限以上帳號可進行CRUD操作

1. 會員系統
   - 含註冊、登入及修改密碼功能
   - 系統管理帳號可於後台進行權限更改
   - 密碼以BCrypt進行加密
2. 相關連結
   - 含分類、圖片、連結、建立日期、排序
   - 前台顯示各分類及其連結數，各分類下顯示連結圖片，點選圖片前往連結位址
   - 後台可進行分類及連結CRUD管理，並可自訂排序及勾選是否開放至前台
3. FAQ
   - 含分類、問題、答案、建立日期、是否置頂、排序*
   - 前台分類頁面顯示所有分類及各分類FAQ題數，FAQ頁面顯示各分類問答
   - 後台可進行分類及連結CRUD管理，並可勾選是否置頂、是否開放並可自訂題目排序
